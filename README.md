# КиноДом

Каталог фильмов. Сейчас в приложении три экрана: главная `/`, страница фильма `/movies/:id` и страница «не найдено» для любого другого адреса.

## Установка и скрипты

```bash
npm install              # установка зависимостей
npm run dev              # сайт на Vite
npm run build            # проверка типов и сборка
npm run preview          # предпросмотр собранного сайта
npm run lint             # проверка кода oxlint
npm run fmt              # форматирование oxfmt
npm run api:generate     # заново собрать клиент TMDB через orval
npm run storybook        # каталог компонентов, порт 6006
npm run build-storybook  # сборка Storybook
```

## Storybook

В каталоге компонентов лежат кнопка, бейдж, карточка фильма, карточка подборки и карусель. Страница «Документация» собирает их варианты на одном экране. Шапка и подвал в Storybook не вынесены: у них нет отдельных состояний, которые стоит смотреть вне страницы.
